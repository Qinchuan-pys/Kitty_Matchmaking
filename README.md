# 毛孩子公园相亲处

一个纯静态网页，使用 GitHub Pages 部署。网页从 `data/dramas.csv` 读取剧集数据，在浏览器中完成筛选与排序，无需服务器或 API Key。

## 功能

- 最低价 / 最高价：按 CSV 的「价格」字段筛选；两个价格都留空时不限价格。
- 默认按播放量从高到低排序。
- 作者、CV1/CV2、剧集类型、tags：作为偏好条件，**不会排除未匹配的剧**；命中偏好越多越靠前。
- 多个作者、CV 或类型采用任意匹配（OR）。
- 会员剧、是否有会员折扣可作为独立筛选条件。
- 可切换播放量、价格、会员折后价格、总集数等排序方式。
- 支持剧名关键词搜索、重置条件、显示结果数量。
- CSV 支持 UTF-8/UTF-8 BOM、标准双引号转义和字段内逗号。

## 1. 准备 CSV

把真实数据放到 `data/dramas.csv`。第一行必须是表头。网页识别以下字段（大小写不敏感，部分字段支持别名）：

| 字段 | 用途 |
|---|---|
| `id` | 剧集唯一 ID |
| `剧名` | 剧名（必需） |
| `作者` | 偏好匹配 |
| `剧集类型` | 偏好匹配 |
| `need_pay` | 付费信息展示；也可作为会员剧字段的备用值 |
| `付费方式` | 付费信息展示 |
| `价格` | 价格筛选（必需） |
| `是否会员剧` | 会员筛选 |
| `是否有会员折扣` | 会员折扣筛选 |
| `播放量` | 默认排序 |
| `总集数` | 展示与排序 |
| `tags` | 标签偏好匹配 |
| `age` | 展示与排序 |
| `会员折扣率` | 展示 |
| `会员折后价格` | 展示与排序，不用于默认价格筛选 |
| `CV1`、`CV2` | CV 偏好匹配 |

表头可以有额外列，网页会忽略未使用的列。建议保留上述原始列名。CSV 应使用 UTF-8 编码；如果某个字段含逗号，需要用双引号括起来，例如 `"甜宠,都市"`。

### 数据值约定

- 数字可以写 `1200000`、`1,200,000`（后者若不加引号会被识别成多列，不建议）或 `120万`。推荐直接写整数。
- 价格建议写纯数字，例如 `20`，不要写 `20元` 以外的复杂文本。
- 「是否会员剧」和「是否有会员折扣」推荐用 `是` / `否` 或 `1` / `0`。
- `tags` 可以用逗号、顿号、分号、竖线或斜线分隔；如用逗号，请用双引号包裹整个 CSV 字段。
- 没有价格的剧：当用户填写价格区间时会被排除；价格留空时则可出现在结果中。
- 会员折后价格只用于显示与可选排序，不参与默认价格筛选。

仓库内的 `data/dramas.csv` 目前只有三行**示例数据**，部署前请替换为真实数据。

## 2. 创建 GitHub 仓库

1. 在 GitHub 新建仓库，例如 `maoer-price-filter`。
2. 上传本项目所有文件，确保 `.github/workflows/deploy.yml` 路径正确。
3. 把分支命名为 `main`（或同步修改 workflow 中的分支名）。
4. 用真实数据覆盖 `data/dramas.csv` 并提交。

## 3. 开启 GitHub Pages

1. 进入仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 中选择 **GitHub Actions**。
3. 进入 **Actions**，确认 `Deploy drama price filter to GitHub Pages` 工作流运行成功。
4. 成功后，Actions 部署步骤会显示网页地址，通常形如 `https://你的用户名.github.io/仓库名/`。

以后只需要更新 `data/dramas.csv` 并提交到 `main`，工作流会自动重新部署最新版本。

## 4. 本地预览

不要直接双击打开 `index.html`，因为浏览器通常会阻止 `file://` 页面读取 CSV。可以在项目目录执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 5. 当前单剧筛选逻辑

1. 先按原价字段「价格」、剧名关键词、会员剧和会员折扣筛选。
2. 作者、CV、类型和 tags 作为偏好项计算匹配数，不会隐藏价格范围内的其他剧。
3. 如果开启「偏好匹配项优先」，按命中的偏好类别数量降序排列。
4. 匹配数相同的剧，再按所选排序方式排列；默认是播放量降序。
5. 如果没有选择任何偏好，所有剧直接按排序方式排列。

注意：`是否会员剧` 优先使用该字段；若该字段为空，程序会尝试用 `need_pay` 推断。若你的数据里 `need_pay` 并不代表会员属性，请确保 CSV 提供正确的「是否会员剧」列，且不要留空。
